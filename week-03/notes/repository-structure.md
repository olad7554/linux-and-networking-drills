# Repository Structure

## Why This Structure
The repository is split into three clear areas:

imported-submissions/ holds a clean copy of the Week 1
and Week 2 work from the shared server. Keeping them
separate makes it easy for a reviewer to find each
week's work without searching through unrelated files.

week-03/ holds the evidence and notes for this Git
workflow task. Keeping it separate from the imported
work means the reviewer can see what was done this
week without it being mixed in with earlier work.

## Imported Work
The files in imported-submissions/ are a direct copy
of the submission folders from the shared server.
No files were modified during the import.

## Week 3 Evidence
The evidence folder contains proof that GitHub access
worked, that a feature branch was used, and that a
pull request was opened.
